# AhaarSetu AI — Backend API & Rule Engine

Node.js + Express.js REST API with deterministic FSSAI compliance rule engine.

## Stack
- Node.js + Express.js
- MongoDB Atlas + Mongoose
- Lyzr AI Multi-Agent SDK
- Deterministic JSON Validator (FSSAI Regulation 5)

## Agents
1. **Vernacular Intake Agent** — speech-to-structured-data
2. **FSSAI & Legal Metrology Compliance Agent** — label validation
3. **Unit Economics & Pricing Agent** — true landed cost calculator
4. **Batch Traceability & Lab-Guardrail Agent** — lot tracking + NABL reminders
