# Contributing to AhaarSetu AI

Thank you for your interest in contributing!

## Setup

```bash
# Clone
git clone https://github.com/KYaswanthReddy/AhaarSetu.git
cd AhaarSetu

# Install server deps
cd server && npm install

# Install client deps
cd ../client && npm install
```

## Branch Naming
- `feat/<feature-name>` for new features
- `fix/<bug-name>` for bug fixes
- `docs/<change>` for documentation

## Commit Style
Follow Conventional Commits: `feat:`, `fix:`, `chore:`, `docs:`, `refactor:`

## Regulatory Boundary
Never allow the AI agents to auto-generate or certify food safety claims.
All label outputs require mandatory human owner sign-off before use.
