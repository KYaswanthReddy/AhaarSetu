# AhaarSetu AI — Frontend (PWA)

React (Vite) + Tailwind CSS offline-first Progressive Web App.

## Stack
- React 18 + Vite
- Tailwind CSS
- vite-plugin-pwa
- Dexie.js (IndexedDB for offline storage)
- jsPDF + html2canvas (client-side PDF label generation)
- qrcode.react (QR Batch Passport generation)
- Bhashini API / Web Speech API (vernacular voice input)

## Setup (coming in Phase 3)
```bash
npm install
npm run dev
```
